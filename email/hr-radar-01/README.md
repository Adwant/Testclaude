# HR-радар №1 — вёрстка письма

`index.html` — готовое письмо, 600 px, table-based, без внешних зависимостей кроме картинок.

## Перед отправкой

1. Заменить `{{CDN}}` на базовый URL хостинга картинок (без слэша на конце).
2. Заменить `{{unsubscribe}}` на токен отписки вашей рассылочной системы.
3. Прогнать через инлайнер CSS **не нужно** — все стили уже инлайновые, в `<style>` остались только медиазапросы и ресеты, которые инлайнить нельзя.

## Решения по совместимости

**Скругления убраны** у всех карточек, плашек и тегов — в Outlook (движок Word) `border-radius` не работает, и углы получались рваными. Скругление осталось только у двух кнопок: они собраны как bulletproof-кнопки с VML `roundrect`, который Outlook рисует корректно, `arcsize="50%"` даёт ту же пилюлю, что в макете.

**Градиенты заменены на плоские цвета.** В Outlook градиенты не поддерживаются вообще, в остальных клиентах ведут себя по-разному. Взял усреднённый тон каждой карточки:

| Карточка | Градиент в макете | Плоский цвет в письме |
|---|---|---|
| Внешний контур, врезка, стат №1 | `#E9F1FD → #C8D6EE` | `#DCE8F7` |
| Навигатор, стат №2 | `#FFFFFF → #FFF3AE` | `#FFF8D2` |
| Карта трендов | `#E4EFFE → #A6CCFF` | `#C9DEFE` |
| Запуски | `#FDFAEF → #EDE3CE` | `#F6F1E2` |
| Топ-5 навыков | `#010028 → #3D4E7A` | `#1E2750` |
| Стат №3 | `#EEF5F2 → #C6D3CC` | `#DCE4E0` |
| Кто в зале | `#FFFEFA → #EDE3CE` | `#F7F1E4` |

**Герой — картинкой**, потому что там текст поверх градиента с лентой. Две версии, переключаются медиазапросом: `hero-600.png` для десктопа, `hero-375.png` для мобильных. Под картинкой стоит `bgcolor="#131C42"` — если картинки отключены, блок остаётся тёмным, а не белым провалом, и виден `alt` с датой и темой.

**Полупрозрачности на тёмном пересчитаны в непрозрачные цвета** — сегменты таймлайна, разделители таблицы, приглушённый текст. `rgba` в Outlook даёт чёрный.

**Щели между блоками.** Все ячейки с картинками и распорками получили `font-size:0;line-height:0`, у `img` — `display:block;border:0`. Это то, из-за чего обычно вылезают тонкие светлые полосы по краям блоков.

**Автоссылки.** Даты и время (`24 сентября, среда`, `11:00 — 12:00 мск`) Gmail и Outlook.com подчёркивают синим как ссылки — на них стоит класс `no-autolink`, который возвращает наследуемый цвет.

**Тёмная тема.** Стоят `meta color-scheme` / `supported-color-schemes` в light. Apple Mail и Outlook тему не инвертируют; Gmail на Android может слегка притемнить белый фон — это единственный клиент, где полного контроля нет.

**Шрифты.** Inter в письмах не грузим: Gmail его вырезает, а частичная поддержка даёт разъезжающиеся строки. Стек `'Inter', Arial, Helvetica, sans-serif` — у кого Inter стоит в системе, увидит его, остальные Arial. Кегли и интерлиньяж подобраны так, чтобы Arial не ломал вёрстку.

## Мобильная адаптация

**`max-width:620px`** — основной брейкпоинт: контейнер на 100 %, поля секций 32 → 20, карточки 24 → 18, H1 38/45 → 27/33, H2 24/30 → 20/26, заголовки карточек 21/27 → 18/24, иконки 46 → 40 и 40 → 34, колонка лейблов в таблице 120 → 92 px. Блок из трёх цифр остаётся в три колонки, как в мобильном макете.

**`max-width:370px`** — для iPhone SE и старых Android: поля 16 px, три цифры разворачиваются в столбик, у тегов снимается `nowrap` и кегль падает до 12. Без этого блок цифр и ряды тегов распирали письмо шире экрана и появлялся горизонтальный скролл.

Прогнал вёрстку в Chromium на 700 / 600 / 480 / 414 / 375 / 360 / 320 px — горизонтального переполнения нет ни на одной ширине.
