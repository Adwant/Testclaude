# Спортика · Стиль 1

Мобильный прототип по макету Figma «Sportika (Style2)», страница «Спортика · Экраны».
React 18 + TypeScript + Vite + Framer Motion. Рассчитан на ширину 375–430 px (iPhone), учитывает safe-area.

## Запуск

```bash
npm ci
npm run dev       # http://localhost:5173/  (сплэш) и /1/ (приложение)
npm run build     # → dist/
```

## Что в сборке

```
dist/
  index.html      сплэш «Выберите стиль» → /styles/
  1/index.html    стиль 1 (это приложение) → /styles/1/
  assets/         js, css, шрифт Onest, 3D-рендеры (webp)
```

Стиль 2 кладётся рядом в `dist/2/` (или прямо на сервер в `/styles/2/`). Пока его нет, карточка на сплэше показывает «Скоро».
Все пути относительные — сборку можно положить в любую подпапку.

## Деплой на sportika.estvkus.ru/styles/

Вариант 1 — вручную: `npm run build` и скопировать содержимое `dist/` в каталог, который отдаётся по `/styles/`.

Вариант 2 — GitHub Actions (`.github/workflows/deploy-sportika.yml`): добавьте секреты репозитория
`DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`, `DEPLOY_PATH` — после этого каждый пуш в `sportika/` выкладывается автоматически.

## Структура

- `src/styles/tokens.css` — токены из переменных Figma (цвета, радиусы, отступы, типографика Onest)
- `src/ui/` — компоненты: кнопки, чипы, карточки, плашки, штриховой прогресс, сегменты, шторки, диалоги, таб-бар, анимированные числа, 3D-иллюстрации, иконки
- `src/screens/` — онбординг, главная (15 состояний), цель дня, серия, спортики, задания/вызовы/челленджи, активность, призы, профиль
- `src/data/` — данные экранов

## Анимации

Числа докручиваются при появлении и при изменении; штриховые шкалы и линия графика прорисовываются; столбцы и дни календаря появляются по очереди;
стопка «Вызовы дня» раскладывается/складывается; шторки выезжают снизу и закрываются свайпом; экраны въезжают справа, назад — свайп от левого края;
лёгкие анимации иконок (шаги, пламя, метка, колокольчик, предупреждения); 3D-объекты «парят». При «Уменьшить движение» в iOS анимации отключаются.

## Демо-состояния

Профиль → «Состояния экранов» — все состояния из макета (главная, онбординг, вызовы, челленджи, активность, призы, профиль) и сброс прототипа.
